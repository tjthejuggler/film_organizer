      Seen log

      Record movies/series you have watched but no longer own — just so the catalog knows you've seen them. These entries survive scans even though no file exists. If the file ever reappears on disk, the entry turns into a normal library row (still marked watched).

      Duplicate copies

      The same title found in more than one place (e.g. laptop and an external drive), or cataloged twice as two rows. Keep the bigger copy for best quality — the size difference is shown. Deleting a copy removes its files from disk and updates the catalog. The server refuses any deletion that would leave you with no copy at all.
