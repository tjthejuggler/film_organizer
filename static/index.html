API keys & providers

TMDB provides posters, cast, creators, ratings. OMDb (optional) adds IMDb ratings. The LLM (z.ai) cleans up messy folder names when normal matching fails — just paste your z.ai key, base URL and model are prefilled.

Library roots

Folders to catalog — laptop paths now, external drives later. Drives that are unplugged are kept and shown as offline.

    Duplicate copies

    The same title found in more than one place (e.g. laptop and an external drive), or cataloged twice as two rows. Keep the bigger copy for best quality — the size difference is shown. Deleting a copy removes its files from disk and updates the catalog. The server refuses any deletion that would leave you with no copy at all.
